# Обновление для Flutter и Dart — серии мероприятий и рейтинг

Одно мероприятие теперь может быть выпуском серии. У каждого выпуска остаётся собственный ID события, карточка, запись и билеты. Выпуски проходят обычную модерацию.

## Как добавить выпуск

В существующий `POST /api/events` можно добавить одно поле:

- `"seriesTitle": "Ежегодный кубок Дона"` создаёт новую серию. Вид спорта берётся из заявки.
- `"seriesId": 4` связывает новый выпуск с существующей серией того же организатора и вида спорта.
- Без этих полей создаётся разовое событие. Ответ для выпуска содержит дополнительно `seriesId`. В `GET /api/events/{id}` поле `seriesId` присутствует у связанных мероприятий.

## Запросы

| Метод и путь | Доступ и назначение |
| --- | --- |
| `GET /api/series/mine` | JWT. Серии текущего организатора как массив `{id,title,sport}`. Используйте для выпадающего списка при создании мероприятия |
| `PUT /api/events/{id}/series` | JWT владельца события или администратора. Принимает `{"seriesId":4}` или `{"seriesTitle":"Ежегодный кубок Дона"}`. Возвращает `{"seriesId":4}`. Подходит для привязки уже прошедших мероприятий |
| `GET /api/series/{id}` | Публичные сведения о серии и опубликованных выпусках. Пока выпусков нет в публичном доступе, сводку может открыть организатор или администратор |
| `GET /api/organizers/leaderboard?year=2025` | Публичный рейтинг организаторов и количество подходящих событий за выбранный год |
| `GET /api/series/leaderboard?year=2025` | Публичный рейтинг серий. Элементы содержат `id,title,sport,owner,organizer,events,years` |

`PUT` принимает ровно один вариант привязки. Повтор запроса с тем же `seriesId` безопасен. Для уже связанного выпуска смена серии вернёт `409`. Отсутствующая или чужая серия вернёт `404`, вид спорта другой — `409`. Чужой выпуск обычный пользователь редактировать не может.

## Хронология

Ответ `GET /api/series/{id}` содержит `id,owner,title,sport,organizer,city,firstYear,yearsHeld,editions`. Выпуски идут по времени начала от ранних к поздним. Например:

```json
{
  "id": 42,
  "title": "Ежегодный кубок Дона",
  "start": "2025-07-01T09:00:00.000Z",
  "place": "Парк Левобережный",
  "duration": 90,
  "attended": 18,
  "edition": 4,
  "year": 2025,
  "seriesYear": 4,
  "completed": true
}
```

- `edition` — позиция среди опубликованных выпусков. Если организатор привязал более раннее событие, сервер пересчитает нумерацию. Для ссылок используйте `id`.
- `year` — календарный год начала по Москве. `seriesYear` отсчитывается от первого опубликованного выпуска. Например, если первый выпуск был в 2022 году, то в 2025 идёт 4-й год серии. Несколько выпусков в одном году имеют разные `edition`, но одинаковый `seriesYear`.
- `yearsHeld` — количество разных лет с завершёнными опубликованными выпусками. `firstYear` равен `0`, если публичных выпусков пока нет.
- Для вкладки истории используйте `completed == true`, для ближайших выпусков — `completed == false`. `attended` считает подтверждённые посещения.

## Рейтинг

Без `year` оба запроса считают все годы. Ответ рейтинга организаторов содержит `years: [{"year":2025}]` со списком доступных периодов. В рейтинг попадают завершённые одобренные события активных организаторов с хотя бы одним подтверждённым участником. Место определяется количеством таких событий. При равном числе выпусков серии с большим числом сезонов за выбранный период идут выше. Серии и рейтинг сейчас доступны для Ростова-на-Дону.
